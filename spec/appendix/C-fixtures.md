## C.2 比對規則

| 情境 | 標準 |
| --- | --- |
| 一般數值 | 相對誤差 $< 10^{-6}$ |
| 期望值為 0 或 `null` | 絕對誤差 $< 10^{-9}$，或型別必須為 `null` |
| 分類欄位（`skewClass`、`performanceFocus`） | 字串完全相等 |
| `tailCount`、`n` | 整數完全相等 |

**`null` 與 0 不得互相接受。** 這是本組向量最重要的一條比對規則：V3 的相關係數必須是 `null`，若實作回傳 `0.0` 即為失敗。

### 這張表裡的「如果算錯會長怎樣」

| 症狀 | 幾乎可以確定的原因 |
| --- | --- |
| V1 的 $\sigma_p$ 算出 `0.180091` 而非 `0.180452` | `np.std` 沒帶 `ddof=1`（母體標準差） |
| V1 的 $G_1$ 算出 `-0.181647` 而非 `-0.182746` | 用了母體偏態 $b_1$（見 V8） |
| V1 的 $G_2$ 算出 `3.4` 附近 | 用了 Pearson 峰度而非超額峰度 |
| V3 的相關係數算出 `0.0` 而非 `null` | 零變異用 `== 0` 判定（§4.1.0 步驟 4b） |
| V4 的 Sortino 算出 `inf` 或極大值 | $DD=0$ 時沒有回 `null` |
| V6 的 $PCR$ 全為正 | 對負 RC 取了絕對值 |
| V7b 的分類為 `undetermined` | $n \ge 30$ 的門檻寫成 $n > 30$ |
| $\sqrt{w^\top\Sigma w}$ 與 $\sigma_p$ 不相等 | 共變異數矩陣沒有年化（少乘 252），或權重來源不一致 |

**$\sqrt{w^\top\Sigma w}$ 與年化波動度在全部八組中完全相等**，這是驗證兩條計算路徑一致性最有效的一項（對應驗收項 D14）。

$\sum PCR$ 的顯示值因四捨五入至 6 位而可能為 `0.999999` 或 `1.000001`；**實際比對時以未經捨入的值計算，容差 $10^{-9}$**（驗收項 D13）。

**V6 是最重要的一組**：第 2 檔的 $RC$ 為負（抵銷效果），導致第 1 檔的 $PCR$ 達 132.8%。這在數學上完全正確，但看起來「不合理」，是最容易被實作者「順手修正」成絕對值或 0 的地方。

## C.7 V8：$G_1$ 與母體偏態的關係

| 項目 | 值 |
| --- | --- |
| $n$ | 250 |
| 母體偏態 $b_1$ | `-0.181647` |
| 樣本偏態 $G_1$ | `-0.182746` |
| 實測比值 $G_1/b_1$ | `1.006046` |
| 理論比值 $\sqrt{n(n-1)}/(n-2)$ | `1.006046` |

兩者相差僅 0.6%，肉眼比對時看起來「差不多」——**這正是它危險的原因**。驗收項 D11 要求明確驗證兩者不同，而不是驗證「值接近預期」。

合計 110 個案例，全部以 `pytest.mark.parametrize` 執行，**不得抽樣**。

這些規則是純查表運算，窮舉的執行成本以毫秒計；而漏掉任何一格，都會讓落在該格的使用者得到錯誤的風險屬性，且系統不會有任何異常徵兆。

問卷向量以 CSV 置於 `tests/fixtures/questionnaire_vectors/`，每組一檔，欄位為「輸入答案 → 預期結果」。
