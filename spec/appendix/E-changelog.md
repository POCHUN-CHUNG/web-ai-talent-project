## 1.0.0 的決策來源

本版由六輪對談逐步定案，完整過程見 `spec/00-cross-check.md`。

| 輪次 | 主要裁示 |
| --- | --- |
| 第一輪（D-01 ~ D-05） | 分析期間改為 1–10 年滑桿；股價採 yfinance；**推翻指標說明書的 $R_f=0\%$**，改用五家公股銀行定存平均；AI 模型採 Gemini 3.5 Flash |
| 第二輪（D-06 ~ D-09） | $R_f$ 取五家算術平均、最新一筆；滑桿預設 5 年；資料不足時自動限縮至最長共同期間 |
| 第三輪（D-10 ~ D-13） | **$MAR = R_f$**，下行波動度公式改寫；報告只提供核心四張圖；熱圖採語意色發散；壓力測試列為非目標 |
| 第四輪（D-14 ~ D-21） | 微調只開放意願類欄位；問卷可重填、分析全數留存；成本不進 AI；`limited` 擋住流程；RC 顯示前 5 名；密碼規則維持現況；Q11 選項調整 |
| 第五輪（D-22 ~ D-30） | 持股改為**交易明細**；市場基準改 `IR0001`；不支援賣出；圖表改用 Nivo；實際績效只做持有天數與年化持有報酬；API 不加版本前綴；字型走 Google Fonts |

## 變更規格的流程

1. 先改 `spec/` 底下的對應文件，**不得先改程式**（`SPEC.md` §0.2 契約優先）。
2. 更新該文件與 `SPEC.md` 標頭的版本號。
3. 在本檔新增一列，寫明變更內容與影響範圍。
4. 若變更觸及 §4.1 的任何公式，必須同步重新產生 `spec/appendix/C-fixtures.md` 的黃金向量，並更新其 `vector_version`。
5. 若變更觸及契約層欄位，必須同步檢查 `spec/prompts/` 的 payload 說明是否需要修改。
