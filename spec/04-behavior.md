## 4.1 核心演算法

本節的每一條公式都是**唯一實作依據**。所有指標由後端算定，AI 不參與任何計算。
數值驗證向量見 `spec/appendix/C-fixtures.md`，比對標準為相對誤差 < 1e-6（P-20）。
**每條公式的文獻出處見 `spec/appendix/D-references.md` §D.2**；該附錄同時標明哪些門檻是本專題自訂、不具官方依據。

### 4.1.0 共同前置

**步驟 1：彙總部位與權重**

依 `holding_lots` 以 `symbol` 分組：

$$Q_i=\sum_k q_{ik},\qquad V_i=Q_i\cdot P_i,\qquad w_i=\frac{V_i}{\sum_{j=1}^{N}V_j}$$

$P_i$ 為該檔在**共同期間最後一個交易日**的 `adj_close`。$\sum w_i = 1$。
**買進日期不參與權重計算**（FR-26）。這是「固定目前權重的歷史模擬」，是刻意的口徑選擇。

**步驟 2：決定共同期間**

1. 目標區間為 `[今日 − requestedYears 年, 今日]`。
2. 對每一檔持股取其在目標區間內的 `trade_date` 集合。
3. 共同期間 = 所有持股交易日集合的**交集**，再與基準 `IR0001` 的交易日集合取交集。
4. `startDate` 與 `endDate` 為交集的最小與最大值，`tradingDays` 為交集大小。
5. 交集為空或大小 < 2 → `INSUFFICIENT_PRICE_DATA`。
6. 若 `effectiveYears < requestedYears`，將造成限縮的代號（其最早交易日 > 目標起點者）列入 `limitedBy`。

取交集而非聯集的理由：所有指標必須建立在同一組交易日上，否則共變異數矩陣的各元素來自不同樣本，數學上不成立。

**步驟 3：報酬序列**

$$R_{i,t}=\frac{P_{i,t}-P_{i,t-1}}{P_{i,t-1}}$$

$n = \text{tradingDays} - 1$ 為有效日報酬筆數。價格一律取 `adj_close`。

**步驟 4：組合日報酬與基準日報酬**

$$R_{p,t}=\sum_{i=1}^{N}w_i R_{i,t},\qquad R_{m,t}=\frac{M_t-M_{t-1}}{M_{t-1}}$$

$M_t$ 為 `IR0001` 的當日值。

**步驟 4b：零變異判定**

凡需要判斷「標準差為零」「變異數為零」的地方，**一律以 $\sigma < 10^{-12}$ 判定，不得用 `== 0`**。

理由不是理論而是浮點數的實際行為：常數序列的樣本標準差**不會剛好等於 0**。以 250 筆固定值 0.0005 為例，`np.std(x, ddof=1)` 回傳 $1.09\times10^{-19}$ 而非 0。用 `== 0` 判定會整條路徑失效，接著以該值當分母，產生「相關係數 0.0」這種看起來合理、實際上毫無意義的結果，而且**不會拋任何例外**。

適用位置：Sharpe 的分母 $\sigma_p$、Sortino 的分母 $DD_{\text{annual}}$、Beta 的分母 $\text{Var}(R_m)$、相關係數的分母 $\sigma_i\sigma_j$、RC 的分母 $\sigma_p$、偏態與峰度的標準化分母 $s$。

門檻取 $10^{-12}$ 的依據：日報酬的典型量級為 $10^{-2}$，門檻低於它 10 個數量級，不會誤判任何真實的低波動序列。

**步驟 5：無風險利率**

$$R_f=\frac{r_{\text{taiwan}}+r_{\text{tcb}}+r_{\text{land}}+r_{\text{huanan}}+r_{\text{first}}}{5\times 100}$$

資料表欄位以百分比儲存（`1.690` 代表 1.690%），故除以 100 轉為小數。

$$R_{f,\text{daily}}=(1+R_f)^{1/252}-1,\qquad MAR=R_f$$

**禁止**使用 $R_f/252$ 的簡單除法。兩者在 $R_f \approx 1.7\%$ 時差異雖小，但複利換算才與幾何年化的報酬定義一致。

### 4.1.1 年化報酬率

$$R_{p,\text{annual}}=\left(\prod_{t=1}^{n}(1+R_{p,t})\right)^{252/n}-1$$

**禁止**改用 $\bar{R}_p \times 252$（算術年化）。兩者在波動大時可差 10% 以上，且算術年化無法對應實際累積報酬。

若任一 $(1+R_{p,t}) \le 0$（組合單日跌幅達 100%，實務不可能）→ 標為 `unavailable`，`reason` 為「報酬序列含非正累積因子」。

### 4.1.2 年化波動度 σp

$$\sigma_{\text{daily}}=\sqrt{\frac{1}{n-1}\sum_{t=1}^{n}(R_{p,t}-\bar{R}_p)^2},\qquad \sigma_p=\sigma_{\text{daily}}\sqrt{252}$$

**樣本標準差，`ddof=1`。** NumPy 的 `np.std` 預設 `ddof=0`（母體），直接呼叫會得到偏小的值。必須寫 `np.std(x, ddof=1)`。

| 邊界 | 處理 |
| --- | --- |
| $n < 2$ | `unavailable`，`reason`「有效日報酬不足」 |
| $\sigma_p = 0$ | 值為 0，`available`。但 Sharpe 因分母為零而 `unavailable` |

### 4.1.3 年化下行波動度 DD

$$DD_{\text{daily}}=\sqrt{\frac{1}{n}\sum_{t=1}^{n}\min\left(R_{p,t}-R_{f,\text{daily}},\,0\right)^2},\qquad DD_{\text{annual}}=DD_{\text{daily}}\sqrt{252}$$

三個容易寫錯的點：

1. **分母是 $n$，不是「低於門檻的天數」。** 這是下行偏離（downside deviation）的定義，不是「只取負報酬樣本再求標準差」。
2. **門檻是 $R_{f,\text{daily}}$，不是 0。** 本版 $MAR = R_f$（D-10），原指標說明書的 $\min(R_t, 0)$ 公式已作廢。
3. **不減平均數。** 與標準差不同，下行偏離是相對於門檻，不是相對於樣本平均。

| 邊界 | 處理 |
| --- | --- |
| 所有 $R_{p,t} > R_{f,\text{daily}}$ | $DD = 0$，`available`；Sortino 因分母為零而 `unavailable` |
| $n < 2$ | `unavailable` |

### 4.1.4 Beta 與 R²

$$\beta_p=\frac{\text{Cov}(R_p,R_m)}{\text{Var}(R_m)},\qquad R^2=\text{Corr}(R_p,R_m)^2$$

共變異數與變異數皆為**樣本值（`ddof=1`）**。在單因子含截距的迴歸下，$R^2$ 等於相關係數平方，不需另跑最小平方法。

| 邊界 | 處理 |
| --- | --- |
| $\text{Var}(R_m)=0$ | 兩者皆 `unavailable`，`reason`「基準報酬無變異」 |
| 基準在共同期間無資料 | 整個分析回 `BENCHMARK_UNAVAILABLE`（步驟 2 已取交集，正常不會走到這裡） |
| $n < 2$ | 兩者皆 `unavailable` |

**禁止**以 Beta 推算未來跌幅。這條寫在 AI Prompt 裡，後端也不得提供任何此類衍生欄位。

### 4.1.5 最大回撤 MDD

$$V_t=\prod_{\tau=1}^{t}(1+R_{p,\tau}),\qquad \text{Peak}_t=\max_{\tau\le t}V_\tau,\qquad DD_t=\frac{V_t-\text{Peak}_t}{\text{Peak}_t}$$

$$MDD=\min_t DD_t$$

$V_0 = 1$。$\text{Peak}_t$ 的範圍包含 $V_0$，因此 $MDD \le 0$ 恆成立。

**回傳值保留負號**（例 `-0.2837`）。前端顯示時才轉為「−28.37%」。契約中留負號是為了讓大小比較不會因符號而顛倒。

同時輸出回撤走勢圖所需的序列：`[{date, navIndex, drawdown}]`，其中 `navIndex` 為 $V_t$、`drawdown` 為 $DD_t$。

### 4.1.6 95% 單日預期短缺 ES95

$$q_{0.05}=\text{Quantile}_{5\%}(R_p),\qquad ES_{95}=-\mathbb{E}\left[R_p\mid R_p\le q_{0.05}\right]$$

**分位數採線性內插**（NumPy 預設 `method="linear"`，等同 R 的 type 7）。分位數估計方法有九種，不同方法在小樣本下結果明顯不同，必須指定。

| 邊界 | 處理 |
| --- | --- |
| 尾端樣本數 | 因資料重值，實際落在尾端的筆數可能不等於 $n \times 5\%$。輸出 `tailCount` 供圖說使用 |
| $ES_{95} < 0$ | 代表最差 5% 交易日的平均仍為正報酬。**保留負值**，不改為 0，不宣稱「不會虧」 |
| $n < 20$ | `available`，但 `dataQuality.notes` 加入「尾端樣本不足 20 筆，ES 估計不穩定」 |

### 4.1.7 樣本偏態係數 G1

$$G_1=\frac{n}{(n-1)(n-2)}\sum_{t=1}^{n}\left(\frac{R_{p,t}-\bar{R}_p}{s}\right)^3$$

$s$ 為樣本標準差（`ddof=1`）。

**禁止使用 `scipy.stats.skew`。** 它預設回傳母體偏態（$b_1$，分母為 $n$），與本式的 $G_1$ 不同。兩者比值為 $\sqrt{n(n-1)}/(n-2)$，在 $n=1000$ 時差異約 0.15%，看起來很小，但會讓黃金向量比對失敗，且與文獻引用的定義不一致。本專案**不安裝 scipy**（`spec/02-system.md` §2.1）。

| 邊界 | 處理 |
| --- | --- |
| $n < 3$ | `unavailable`（分母為零） |
| $s = 0$ | `unavailable`，`reason`「報酬無變異」 |

### 4.1.8 樣本超額峰度 G2

$$G_2=\frac{n(n+1)}{(n-1)(n-2)(n-3)}\sum_{t=1}^{n}\left(\frac{R_{p,t}-\bar{R}_p}{s}\right)^4-\frac{3(n-1)^2}{(n-2)(n-3)}$$

**超額峰度，常態分布的參考值為 0**，不是 Pearson 峰度的 3。

| 邊界 | 處理 |
| --- | --- |
| $n < 4$ | `unavailable` |
| $s = 0$ | `unavailable` |

### 4.1.9 HHI 與有效持股檔數

$$HHI=\sum_{i=1}^{N}w_i^2,\qquad N_{\text{eff}}=\frac{1}{HHI}$$

$N_{\text{eff}}$ **由前端計算**，不列入 `metrics`，不送給 AI（D2 §八）。

$N=1$ 時 $HHI=1$、$N_{\text{eff}}=1$，皆為合法值。

### 4.1.10 風險貢獻度 RC 與 PCR

以**年化共變異數矩陣** $\Sigma = \Sigma_{\text{daily}} \times 252$（樣本共變異數，`ddof=1`）計算：

$$\sigma_p=\sqrt{w^\top\Sigma w},\qquad RC_i=w_i\frac{(\Sigma w)_i}{\sigma_p},\qquad PCR_i=\frac{RC_i}{\sigma_p}$$

恆等式 $\sum_i RC_i = \sigma_p$ 與 $\sum_i PCR_i = 1$ 必須成立，實作後以此自我驗證（容差 1e-9）。

用年化矩陣而非日矩陣，是為了讓這裡算出的 $\sigma_p$ 與 §4.1.2 的年化波動度**在數值上一致**。兩者理論上相等；若相差超過 1e-9，代表權重或共變異數的來源不一致，應直接拋錯而非取其一。

| 邊界 | 處理 |
| --- | --- |
| $\sigma_p = 0$ | 全部 `rc` 與 `pcr` 為 `null`，不硬算，不做來源排名 |
| $RC_i < 0$ | **合法**。代表該檔在本次共變異數結構下有抵銷效果。**不得改為 0、不得取絕對值**。其他持股的 $PCR$ 因此可能超過 100% |
| $N=1$ | $RC_1=\sigma_p$、$PCR_1=1$ |

### 4.1.11 相關係數矩陣

$$\rho_{ij}=\frac{\text{Cov}(R_i,R_j)}{\sigma_i\sigma_j}$$

Pearson 相關係數，樣本值。輸出為對稱方陣，對角線為 1。

| 邊界 | 處理 |
| --- | --- |
| 任一檔 $\sigma_i=0$ | 該檔所有非對角線元素為 `null`，**不得填 0**（0 代表「無線性關聯」，與「無法計算」意義完全不同） |
| $N=1$ | 矩陣為 `[[1]]`，熱圖 `status` 為 `unavailable`，`reason`「只有一檔持股，沒有可比較的配對」 |

### 4.1.12 夏普比率與索丁諾比率

$$\text{Sharpe}=\frac{R_{p,\text{annual}}-R_f}{\sigma_p},\qquad \text{Sortino}=\frac{R_{p,\text{annual}}-MAR}{DD_{\text{annual}}}$$

本版 $MAR=R_f$（D-10），因此兩者分子相同、分母不同。

| 邊界 | 處理 |
| --- | --- |
| $\sigma_p=0$ | Sharpe `unavailable`，`reason`「總波動為零」 |
| $DD_{\text{annual}}=0$ | Sortino `unavailable`，`reason`「無低於無風險利率的交易日」 |
| 結果為 $\pm\infty$ 或 NaN | `unavailable`，**不得回傳無限大** |

**禁止**把「Sortino 數值較大」解讀為風險較低。兩者分母的定義不同，數值大小不可直接比較。

### 4.1.13 偏態分類與績效解讀順序

後端依 $G_1$ 判定分類，AI 只能引用結果，不得自訂門檻（D2 §5.4）。

| 條件 | `skewClass` | `performanceFocus` |
| --- | --- | --- |
| $G_1$ 為 `unavailable` 或 $n < 30$ | `undetermined` | `undetermined` |
| $\lvert G_1\rvert < 0.5$ | `near_symmetric` | `sharpe_primary` |
| $G_1 \ge 0.5$ | `positive_skew` | `both` |
| $G_1 \le -0.5$ | `negative_skew` | `sortino_primary` |

Sharpe 或 Sortino 任一為 `unavailable` 時，`performanceFocus` 一律覆寫為 `limited`，不論偏態分類為何。

0.5 這個門檻採統計學常見的經驗判準（$\lvert\text{skew}\rvert < 0.5$ 視為近似對稱）。`interpretation.ruleSource` 欄位固定填 `"本專題規則 v1.0：|G1| < 0.5 視為近似對稱"`，讓 AI 與使用者都知道這不是官方公式。

### 4.1.14 計算複雜度與效能

| 步驟 | 複雜度 | $N=50$、$T=2520$ 的量級 |
| --- | --- | --- |
| 報酬序列 | $O(NT)$ | 126,000 |
| 共變異數矩陣 | $O(N^2T)$ | 6,300,000 |
| $\Sigma w$ | $O(N^2)$ | 2,500 |
| 其餘純量指標 | $O(T)$ | 2,520 |

全部以 NumPy 向量化實作，實測應遠低於 §1.3 的 3 秒預算。**禁止**以 Python 迴圈逐日累加——不只是慢，浮點累加順序不同會讓結果無法重現。

### 4.1.15 禁止的實作方式總表

| 禁止 | 原因 |
| --- | --- |
| `np.std(x)` 不帶 `ddof=1` | 預設為母體標準差，系統性偏小 |
| `scipy.stats.skew` / `kurtosis` | 預設為母體動差，與 $G_1$、$G_2$ 定義不同 |
| 引入 `pandas` | 體積遠大於需求；且 `DataFrame.std()` 預設 `ddof=1`、`np.std()` 預設 `ddof=0`，混用兩者是經典錯誤來源 |
| $R_f/252$ | 與幾何年化不一致，應用 $(1+R_f)^{1/252}-1$ |
| $\bar{R}_p\times 252$ | 算術年化無法對應實際累積報酬 |
| $\min(R_t,0)$ 作為下行偏離 | 舊版公式，門檻應為 $R_{f,\text{daily}}$ |
| 以 `close` 代替 `adj_close` | 長期報酬與 Beta 會靜默失真 |
| 缺值填 0 | 0 是有意義的數值，與「無法計算」不同 |
| 取區間中點代替使用者的損失界線 | 使用者只表示了區間，沒表示精確值 |
| 以 `float` 儲存金額 | 一律 `Decimal` 或 `NUMERIC` |
| Python 迴圈逐日累加 | 慢，且浮點累加順序影響可重現性 |
| 以 `== 0` 判斷零變異 | 常數序列的樣本標準差是 $10^{-19}$ 量級而非 0，判定會失效且不報錯。一律用 $< 10^{-12}$（§4.1.0 步驟 4b） |

### 4.2.2 問卷轉換規則

規則來源為柏鈞提供的《指標轉換與風險分析規則說明書》，全部為**固定規則式運算**，不含任何評分加總。
問卷構面的設計依據與「哪些規則是本專題自訂」的完整說明見 `spec/appendix/D-references.md` §D.3 與 §D.4。

**值的寫法**：直接對應單一題目的指標（核心指標一、二與大部分輔助資料），存進 `facts` 的 `value_text` 一律是**選項原文**（「%」前加半形空格）；只有後端運算的結果（流動性需求、財務承受能力、短期韌性、分散投資知識、交叉分析）才使用等級文字。選項原文同時是 Prompt 字典的查表值，兩邊由測試逐字比對。

#### 核心指標一：可接受損失區間（Q13 選項原文）

| Q13 | `lossTolerance` |
| --- | --- |
| A | 未滿 5 % |
| B | 5 - 9 % |
| C | 10 - 19 % |
| D | 20 - 29 % |
| E | 30 % 以上 |

**不得取中點。** Q13 = C 就是「10 - 19 %」，不是 15 %。

#### 核心指標二：投資期限（Q7 選項原文）

問卷的投資期限是使用者**整體投資的預設期限**（題目：「您目前的投資資金，整體而言預計多久不需動用？」），會套用到所有投資組合。不同投資組合的用途不同時，於分析前的設定彈窗依該組合調整（FR-23、D-14，只用於該次分析、不寫回問卷）。Q8 同樣改為針對整體投資提問（「未來 1 年內，從投資中提領資金的機率？」），因為它與 Q4 一起描述的是使用者本人的資金需求，屬於個人屬性，不開放依組合調整（FR-24）。

| Q7 | `investmentHorizon` |
| --- | --- |
| A | 未滿 1 年 |
| B | 1 - 2 年 |
| C | 3 - 4 年 |
| D | 5 - 9 年 |
| E | 10 年以上 |

#### 核心指標三：資金流動性需求（Q8 為主，Q4 為下限）

先由 Q8 得基礎等級，再由 Q4 施加最低限制，取兩者較高者：

| Q4＼Q8 | A 極高 | B 偏高 | C 中等，可先用備用金 | D 偏低 | E 極低 |
| --- | --- | --- | --- | --- | --- |
| A 未滿 1 個月 | 極高 | 高 | 高 | 高 | 高 |
| B 1 - 2 個月 | 極高 | 高 | 中等 | 中等 | 中等 |
| C 3 - 5 個月 | 極高 | 高 | 中等 | 低 | 低 |
| D 6 - 11 個月 | 極高 | 高 | 中等 | 低 | 低 |
| E 12 個月以上 | 極高 | 高 | 中等 | 低 | 低 |

等級高低順序為：極高 > 高 > 中等 > 低。

實作上以「Q8 基礎等級（A 極高、B 高、C 中等、D/E 低）」與「Q4 最低等級（A 高、B 中等、C–E 不限制）」取較高者，結果與上表相同。最低等級高於基礎等級時，`liquidity_need` 的 `raised_by_reserve` 為 `true`（代表是預備金偏少拉高了結果）。

此矩陣的用意是排除「沒有提款計畫 ＝ 沒有流動性需求」這個錯誤推論——完全沒有緊急預備金的人，突發支出時仍可能被迫賣股。

#### 核心指標四：財務風險承受能力（非補償式 MIN 規則）

先將三題各自分級：

| Q3 現金流 | 等級 | | Q4 預備金 | 等級 | | Q9 20 % 損失影響 | 等級 |
| --- | --- | --- | --- | --- | --- | --- | --- |

| B 收支相抵 | 中等 | | B 1 - 2 個月 | 中等 | | B 壓力顯著 | 低 |
| C 略有結餘 | 中等 | | C 3 - 5 個月 | 中等 | | C 有一定負擔 | 中等 |
| D 穩定結餘 | 高 | | D 6 - 11 個月 | 高 | | D 影響輕微 | 高 |
| E 結餘充裕 | 高 | | E 12 個月以上 | 高 | | E 毫無影響 | 高 |

$$\text{financialCapacity}=\min(\text{lv}(Q3),\ \text{lv}(Q4),\ \text{lv}(Q9))$$

| 條件 | 結果 |
| --- | --- |
| 任一為低 | 低 |
| 無低，至少一中等 | 中等 |
| 三者皆高 | 高 |

共 27 種組合，全部由此規則決定，**不需列舉**。這是**非補償式規則**：一個重大財務弱點不能被其他良好條件抵銷。

**限制因素 `limiting_fact_ids`**：落在最低等級的那幾項（`cash_flow`、`emergency_reserve`、`loss_impact_20pct` 之中），讓 AI 不必重算就能說明「是哪些條件決定了結果」。結果為「高」（三項都沒有限制）時為空陣列。例：Q3 = C（中等）、Q4 = B（中等）、Q9 = D（高）→ 中等，`["cash_flow", "emergency_reserve"]`。

**AI 不得修改此等級**，亦不得因年齡、所得、經驗或損失意願高而推翻（D2 §四）。

### 4.3.3 治理原則

1. **使用者看到的訊息不得洩漏內部細節**：不含堆疊追蹤、SQL、檔案路徑、內部服務名稱、模型原始輸出。
2. **每個錯誤回應都帶 `trace_id`**，與日誌中的同一欄位對應。
3. **可重試與冪等**：`GET` 與 `DELETE` 天然冪等；`POST /market-data/fetch` 與 `POST /stocks/fetch` 以覆寫達成冪等；`POST /portfolios/{id}/analysis` **不冪等**（每次產生新快照），前端須以送出中狀態阻止重複點擊。
4. **資料不一致絕不自動修復**。例如某檔 `stock_info` 被刪但仍有 `holding_lots`（外鍵應已擋下），發生即代表有人繞過了約束，必須中止並記錄，不得猜測意圖。

**問卷送出到結果頁的流程（D-65）**：使用者按下送出後（送出鈕停用、不顯示遮罩），直接前往結果頁；後端寫入快照後在背景呼叫 AI，結果頁此時只顯示標題、轉圈圈與外框閃爍（不出現任何文字），前端每 2 秒重取最新風險屬性，直到 `sectionsStatus` 不再是 `pending`（最多約 4 分鐘多，涵蓋後端最多 3 次呼叫），才一次顯示指標與四段解析。四項指標**不可調整**，故無存檔與重算問題。作答有衝突時後端回 422、不存檔，前端不進結果頁，留在問卷頁標示衝突題號（D-17）。

**`RiskProfile` 的按鈕（D-67）**：
| 進入方式 | 按鈕 |
| --- | --- |
| 剛填完問卷送出而來 | 「回首頁」、「新增投資組合」（投資組合頁完成前暫導向首頁） |
| 從首頁「風險屬性問卷」進入，顯示最新一份 | 「回首頁」、「重新填寫問卷」 |

**重新填寫的冷卻提示（D-71）**：限流不等到按下「送出問卷」才發作。使用者在結果頁按「重新填寫問卷」時，前端先呼叫冷卻查詢；若剩餘秒數大於 0，**不進入問卷頁**，跳出提示視窗（modal）：標題「填寫的時間過短」，內文「請於 N 秒後再嘗試重新填寫問卷」（每秒倒數），只有「關閉」按鈕；關閉後仍停留在結果頁，可繼續查看結果。直接輸入問卷網址進入時同樣檢查，冷卻中會被退回結果頁並跳出同一個視窗。被 400、422 退回的送出**不存檔、不限流也不呼叫 AI**，可立刻修正後重送；限流只計算成功的送出，發生在「重新評估」按鈕的進入前檢查，以及後端的最後防線（429）。

**問卷頁的「取消」按鈕（D-72、D-93）**：一律顯示在按鈕列左側，按下不送出、直接回「風險屬性」頁。第一次填寫的使用者回去後會看到「開始評估」引導，因此也可以取消。

**「重新產生」的等待畫面（D-74）**：轉圈圈與隱藏內容只用於**剛填完問卷送出**後的等待。按「重新產生」時**不**隱藏指標：頁面維持原樣，外框同樣以背景漸層色閃爍（D-92），解析卡的錯誤說明與按鈕改為「產生中…」，結果回來即停止閃爍；前端每 2 秒輪詢，收到結果後更新——成功則顯示四段解析，再度失敗則回到錯誤說明與「重新產生」按鈕。

**分類色**

| 模式 | 序列 1 | 序列 2 | 來源 token |
| --- | --- | --- | --- |
| 淺色 | `#1e3a8a` | `#0d9488` | `primary-500`、`secondary-500` |
| 深色 | `#1e3a8a` | `#0d9488` | `primary-500`、`secondary-500` |

兩種模式使用同一組色（D-48），與 `DESIGN.md`「primary、secondary、tertiary 在深色模式維持相同 500 填色」的規則一致。

**色盲安全性**：`#1e3a8a` ↔ `#0d9488` 的 CVD 分離度 ΔE 25.7（deutan）、22.8（tritan）、27.2（正常視覺），三者皆遠高於 8 的目標值，兩色的識別性沒有問題。

**已知限制**：`#1e3a8a` 對 `dark-surface`（#000000）的對比約 1.68:1，填色在深色模式下與背景的分離較弱。本版接受此結果（D-48），不另加描邊或加粗。§4.4.4 既有的「兩組以上序列必須有圖例、四組以內加直接標籤」與每張圖的視覺隱藏表格替代（FR-34），已足以讓識別不依賴顏色。

淺色模式下 `#1e3a8a` 對 `surface` 的對比為 10.36:1，無此問題。

| 位置 | 淺色 | 深色 |
| --- | --- | --- |
| $\rho=-1$ | `info` #2563eb | `dark-info` #2563eb |
| $\rho\approx-0.3$ | `info-container` #dfeaff | `dark-info-container` #00124d |
| $\rho=0$ | `surface` #ffffff | `dark-surface` #000000 |

| 735–1068px | 兩欄。核心指標 stat tile 兩欄排列 |
| ≥ 1069px | 三至四欄。內容欄寬約 1080px 置中 |

側邊留白：≥ 735px 為 32px、< 735px 為 16px。任何寬度下皆不得出現**頁面層級**的水平捲動；熱圖容器內部的捲動是允許的例外（FR-47）。

## 4.5 國際化與無障礙

| 項目 | 規範 |
| --- | --- |
| 語言 | 僅繁體中文（台灣）。`<html lang="zh-Hant-TW">`。多語系列為非目標 |
| 不翻譯的內容 | API 欄位名、錯誤碼、token 名稱、程式識別碼、股票代號 |
| 日期格式 | 顯示為 `2026/09/20`；區間顯示為 `2021/09/20 – 2026/09/19` |
| 數字格式 | 千分位逗號；百分比小數 2 位；金額小數 0 位（元）並標註幣別「元」 |
| 無障礙目標 | WCAG 2.2 AA |
| 對比 | 正文與 `on-surface-variant` 皆須達 4.5:1；圖表填色對面色須達 3:1（已於 §4.4.4 以工具驗證） |
| 鍵盤 | 所有互動元素可 Tab 聚焦，順序與視覺順序一致；焦點樣式為 2px `focus-ring` 外框加 1px 偏移；彈窗開啟時焦點鎖在彈窗內，`Esc` 關閉 |
| 圖表 | 每張圖有 `aria-label` 描述它在呈現什麼；資料以視覺隱藏的 `<table>` 提供；**不得僅以顏色編碼意義**（熱圖標數值、長條有直接標籤、回撤有文字標記） |
| 狀態提示 | 錯誤與成功訊息置於 `role="alert"` 容器；載入狀態使用 `aria-live="polite"` |
| 動效 | `prefers-reduced-motion: reduce` 時停用旋轉、位移與淡入動畫，保留透明度變化 |
| 強制色彩模式 | `forced-colors: active` 時，圖表的顏色編碼失效，因此熱圖的數值標籤與長條的直接標籤**不得隱藏** |

宣稱符合 WCAG 2.2 AA，因此 `spec/05-quality.md` §5.5 必須有對應的可執行驗收項；驗收項不存在的條款不得宣稱符合。
