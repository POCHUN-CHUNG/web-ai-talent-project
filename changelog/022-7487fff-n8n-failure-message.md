# 022 · n8n 失敗訊息顯示卡在哪一步

- **Commit**：`7487fff`（PR #13）　**日期**：2026-09-25　**作者**：POCHUN-CHUNG
- **一句話總結**：抓取失敗時，回傳給 n8n 的訊息改為說明是哪個步驟出錯。

## 白話說明

以前不管哪個環節失敗，n8n 收到的訊息都是同一句籠統的說明（例如「抓取上市櫃股票日行情資料」），看不出是卡在鎖定檢查、前置資料檢查還是存檔。這一版讓失敗訊息直接寫出出錯的步驟，排查問題更快。

## 變更檔案

| 檔案 | 異動 | 功能 |
| ---- | ---- | ---- |
| `backend/app/services/n8n_result.py` | 修改 | n8n 回傳格式的共用工具，失敗時可帶入當下步驟的說明。 |
| `backend/app/routers/bank_rates.py` | 修改 | 銀行利率抓取 API，失敗訊息改為對應的步驟。 |
| `backend/app/routers/market_data.py` | 修改 | 每日股價抓取 API，失敗訊息改為對應的步驟。 |
| `backend/app/routers/stocks.py` | 修改 | 股票基本資料抓取 API，失敗訊息改為對應的步驟。 |

## 技術備註

- 成功時的 `message` 維持只寫「做什麼」；失敗時改寫出失敗的階段，仍與成功回應同一層（CLAUDE.md §8）。
