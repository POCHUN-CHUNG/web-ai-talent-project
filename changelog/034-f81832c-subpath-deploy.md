# 034 · 前端支援子路徑部署、新增正式環境 Dockerfile

- **Commit**：`f81832c`（PR #23）　**日期**：2026-09-30　**作者**：POCHUN-CHUNG
- **一句話總結**：前端可以部署在網域的子路徑底下（例如 `/ai-talent-project/`），並新增一份正式環境專用的前端建置檔。

## 白話說明

- **子路徑部署**：正式網站不一定放在網域的根目錄，可能放在某個子路徑底下。前端現在可以從環境變數 `VITE_BASE_PATH` 得知自己放在哪個子路徑，產生的網頁與資源網址都會自動帶上這個前綴；本機開發沒有設定這個變數時，行為完全不變。
- **正式環境建置檔**：新增 `frontend/Dockerfile.prod`，先把前端建置成靜態網頁，再交給 nginx 提供給使用者。建置時可帶入子路徑（`VITE_BASE_PATH`）與後端網址（`VITE_API_BASE_URL`）。
- 同時補上 PR #22 的版本說明（033）。

## 技術備註

- `VITE_` 開頭的設定值是在**建置時**寫進前端檔案的，部署後改 `.env` 不會生效，需要帶入新值重新建置。
