# 025 · 投資組合風險指標參考程式

- **Commit**：`e0fc067`（直接提交至 main）　**日期**：2026-09-27　**作者**：POCHUN-CHUNG
- **一句話總結**：加入 14 支風險指標計算的原型程式與一支示範測試，作為後端正式計算模組的對照與參考。

## 白話說明

- 這些是先寫好的「計算公式草稿」，每個指標一支小程式（波動度、Beta、最大回撤、夏普、索丁諾、預期短缺、HHI、偏態、峰度等），不在網站上執行，是作為實作風險分析時的「標準答案」。
- 另有一支用模擬資料把全部指標印出來的示範程式，可以拿同一組資料比對結果是否一致。
- 系統實際使用的版本已整合、修正為單一檔案 `backend/app/services/risk_metrics.py`（見下一版說明）；這裡的程式只作參考，不會被系統執行。

## 變更檔案

| 檔案 | 異動 | 功能 |
| ---- | ---- | ---- |
| `references/calc_risk_indicators/*.py`（14 支） | 新增 | 各項風險指標的計算原型：年化波動度、Beta、相關係數、下行波動度、有效持股檔數、95% 預期短缺、HHI、最大回撤、R²、風險貢獻度、偏態、超額峰度、夏普比率、索丁諾比率。 |
| `references/calc_risk_indicators/test_risk_metrics.py` | 新增 | 示範與驗證：用模擬資料計算並列印全部指標的示範程式。 |

## 技術備註

- 原型經檢查後，在正式版修正了：最大回撤漏算起點、預期短缺以絕對值轉正、分母為零時回傳 0、索丁諾分子分母門檻不一致、相關係數只算組合對大盤、R² 依賴未安裝的 scipy（詳見 `spec/00-cross-check.md` D-109）。
