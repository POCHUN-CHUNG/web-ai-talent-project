# 037 · 正式環境 nginx 加上單頁應用的網址回退

- **Commit**：`c674356`（PR #26）　**日期**：2026-09-30　**作者**：POCHUN-CHUNG
- **一句話總結**：正式環境直接輸入或重新整理某一頁的網址，不會再出現 404 或空白畫面。

## 白話說明

- **問題**：前端的各個頁面（例如風險屬性頁）不是真正存在的檔案，而是由前端程式自己判斷要顯示哪個畫面。正式環境的 nginx 原本只認得實體檔案，直接輸入這類網址會找不到檔案而顯示 404；網址沒有結尾斜線時則會顯示空白。
- **修正**：新增 nginx 設定，找不到對應檔案時一律交回首頁檔（`index.html`），由前端程式決定要顯示哪個畫面。

## 變更檔案

| 檔案 | 異動 | 功能 |
| ---- | ---- | ---- |
| `frontend/nginx.conf` | 新增 | 正式環境網頁伺服器的設定：找不到的網址一律交給前端處理。 |
| `frontend/Dockerfile.prod` | 修改 | 正式環境的前端建置檔：把上面的 nginx 設定放進容器。 |

## 技術備註

- 只影響使用 `Dockerfile.prod` 的正式環境；本機開發用的 Vite 開發伺服器本來就會處理這種情況。
