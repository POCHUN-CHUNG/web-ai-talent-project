# 017 · 股票基本資料、每日股價與大盤指數抓取

- **Commit**：`b52312d`（PR #8）　**日期**：2026-09-21　**作者**：POCHUN-CHUNG
- **一句話總結**：後端新增「抓取股票基本資料、每日股價與大盤指數」的功能，n8n 只負責啟動與顯示結果。

## 白話說明

以前只有銀行利率會自動抓取。這一版讓後端也能自己抓上市櫃股票／ETF 的基本資料、每日收盤價，以及大盤報酬指數，並存進資料庫。排程時間由 n8n 決定；後端只負責執行、寫入並回報「成功／失敗」與筆數。失敗的批次會自動重試，已寫入的資料不受影響。

## 變更檔案

| 檔案 | 異動 | 功能 |
| ---- | ---- | ---- |
| `backend/app/services/market_data.py` | 新增 | 抓取每日收盤價與大盤指數、寫入資料庫、清理過期資料。 |
| `backend/app/services/stock_info.py` | 新增 | 抓取股票基本資料（代號、名稱、市場別、產業別）。 |
| `backend/app/services/n8n_result.py` | 新增 | 給 n8n 的統一回傳格式（訊息、成功／失敗、成功與失敗筆數）。 |
| `backend/app/routers/market_data.py`、`stocks.py` | 新增 | 只給 n8n 呼叫的抓取入口（需金鑰）。 |
| `backend/app/models.py` | 修改 | 新增股票基本資料與每日行情兩張資料表。 |
| `README.md`、`SPEC.md`、`CLAUDE.md`、`.env.example` | 修改 | 補充抓取流程、相關設定與規範。 |

## 技術備註

- 每日行情以「代號＋交易日」覆寫，重跑不會產生重複資料。
- 保留年數與緩衝天數由環境變數設定。
