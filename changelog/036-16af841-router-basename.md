# 036 · 前端路由加上子路徑前綴

- **Commit**：`16af841`（PR #25）　**日期**：2026-09-30　**作者**：POCHUN-CHUNG
- **一句話總結**：網站放在子路徑底下時，切換頁面的網址會正確帶上子路徑前綴，不會跳回網域根目錄。

## 白話說明

- **問題**：正式網站放在 `/ai-talent-project/` 底下時，前端的頁面切換（例如未登入時導向登入頁）不知道自己在子路徑裡，網址會變成 `/login`，而不是 `/ai-talent-project/login`。
- **修正**：前端路由改為沿用建置設定裡的子路徑（與 034 的 `VITE_BASE_PATH` 同一個值），所有頁面網址都會帶上前綴。本機開發不受影響。

## 變更檔案

| 檔案 | 異動 | 功能 |
| ---- | ---- | ---- |
| `frontend/src/App.tsx` | 修改 | 前端的頁面路由總表：路由加上子路徑前綴設定。 |

## 技術備註

- 使用 Vite 內建的 `import.meta.env.BASE_URL` 作為 React Router 的 `basename`，與 `vite.config.ts` 的 `base` 設定保持同步。
